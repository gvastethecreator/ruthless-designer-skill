# Context Calibration Examples

Use only to test whether the chosen archetype, composition, state coverage, and proof plan fit the product. Do not copy their visual treatment.

## Creative Studio: Color-Grading Workbench

Context card: `studio/editor + create + current shot/timeline + expert repeated use + multi-panel workspace + selected/unsaved/export proof`.

- Wrong reflex: dark dashboard with GPU metrics, render cards, and presets above reduced preview.
- Direction: inspector workbench. Current frame and timeline dominate; scopes support image; controls group by color intent and selected layer.
- Signature move: parameter-to-image tether that reveals which region or range control affects.
- Preserve: keyboard grading speed, undo history, clip selection, comparison mode, export settings.
- Prove: blank project, loaded timeline, selected layer, before/after comparison, unsaved and conflicting edits, collapsed panels, export failure, long clip names, real-size icon alignment.

Pass: artifact clearer, chrome more exact—not merely darker.

## Dashboard: Hospital Capacity Decision

Context card: `dashboard + decide + staffing allocation + time-sensitive uncertain data + document/evidence pane + missing/stale/forecast proof`.

- Wrong reflex: twelve bed-count KPI cards followed by unrelated chart variety.
- Direction: question-led overview plus decision table and evidence pane.
- Signature move: every ward row shows capacity, forecast interval, feed freshness, staffing gap, and threshold that changes decision.
- Preserve: exact values, source timestamps, filter scope, accessible tabular alternative, export/report path.
- Prove: zero capacity, missing feed, stale feed, uncertainty, surge threshold, long ward names, filtered cohort, narrow layout.

Pass: staffing decision faster and more defensible—not more charts.

## Command Center: Regional Fleet Incidents

Context card: `command center + monitor/respond + active incident + continuous high-consequence use + multi-panel shell + alert-flood/handoff/recovery proof`.

- Wrong reflex: neon map, pulsing red cards, fake terminal feed, and auto-sorted alerts with no owner.
- Direction: operator cockpit with incident spine. Map and fleet state orient; selected incident holds freshness, scope, evidence, owner, acknowledgement, actions, and recovery.
- Signature move: recovery rail keeps failed, deferred, and reversible actions visible beside incident.
- Preserve: keyboard triage, timestamp precision, audit trail, acknowledgement, team handoff, partial subsystem visibility.
- Prove: normal baseline, one incident, alert flood, stale GPS source, comms outage, assignment, recovery, resolved state, wallboard mode, operator mode.

Pass: urgency discriminating and stable.

## Browser Game: Co-op Extraction HUD

Context card: `game HUD + act/respond + world/combat focal area + continuous controller use + viewport overlay + noisy-play/input-switch proof`.

- Wrong reflex: admin cards in every corner, translucent sidebar inventory, tiny outline icons, and scrolling status panels.
- Direction: HUD perimeter during play; dedicated full-screen modes for map, inventory, and squad management.
- Signature move: objective and extraction pressure compress into one readable temporal cue rather than another card.
- Preserve: gameplay visibility, controller focus, safe areas, subtitle space, input glyph switching, color-vision-independent state, pause behavior.
- Prove: calm traversal, combat, critical health, objective update, full squad status, controller/keyboard switch, long localization, ultrawide and narrow aspect ratios, bright/dark scenes, reduced motion, stream overlay collision.

Pass: readable at a glance while watching the game—not impressive as a flat mockup.

## Interactive Lab: Water Shader Playground

Context card: `interactive prototype + create/explore + rendered water + occasional direct manipulation + full-screen output/workbench + nonblank/fallback/export proof`.

- Wrong reflex: feature landing page before canvas, or cyber dashboard with logs louder than effect.
- Direction: playable surface first plus compact instrument panel.
- Signature move: controls highlight visible water region or property they affect.
- Preserve: presets, reset, reproducible parameters, performance readout, export.
- Prove: nonblank output, meaningful slider change, extreme values, reset, WebGL fallback, reduced motion, background pause, export failure, mobile controls, representative frame pressure.

## Landing: Architectural Lighting Studio

Context card: `landing + choose/trust + physical fixture and room effect + one-time considered purchase + scroll document + first-viewport/proof/mobile evidence`.

- Wrong reflex: beige luxury hero, oversized serif, three feature cards, and invented hospitality logos.
- Direction: artifact stage plus proof wall. Pair fixture geometry and material with room effect it produces.
- Signature move: light-falloff comparison that moves from object to occupied space.
- Preserve: project inquiry, service area, lead time, maintenance facts, real case material, SEO, analytics, form behavior.
- Prove: small-laptop hero, mobile crop, missing image fallback, room proof, long project names, inquiry errors, honest asset provenance.

## Cross-Context Test

Before approval, ask:

- Would moving this composition unchanged to another example still look plausible?
- Did proof matrix exercise costly moments of this product, or only generic breakpoints?
- Did secondary region quietly take over primary archetype?
- Is main artifact obvious with gradients, shadows, and imagery temporarily removed?

Any `yes` to the first or `no` to the others means the direction is still generic.
