# Security policy

The runtime harness can capture screenshots, console output, and network diagnostics from a target application. Treat every review directory as potentially private until a human checks it.

Report vulnerabilities privately through [GitHub security advisories](https://github.com/gvastethecreator/ruthless-designer-skill/security/advisories/new). Do not attach customer screenshots, credentials, private URLs, tokens, or unpublished product data to public issues.

Supported fixes target the current `master` branch.
