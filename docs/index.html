The diagnosis rail

No praise sandwich. No ornamental roast.

  1. 01Evidence

    Show the visible symptom at a readable scale.

  2. 02User damage

    Name the task, decision, or confidence it harms.

  3. 03Structural cause

    Trace the symptom to hierarchy, layout, system, or source.

  4. 04Exact fix

    Make the next artifact move unavoidable.
